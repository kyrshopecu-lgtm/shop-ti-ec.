# Shop ti ec — demostración de tienda virtual

Sitio estático de prueba con identidad azul marino y dorado, catálogo, buscador, carrito local y preparación de consultas para WhatsApp. Diseñado para presentar la idea de la tienda y sus entregas coordinadas en Quito y Ambato.

## Incluye
- Diseño adaptable a celulares y computadoras.
- Catálogo demostrativo con categorías y búsqueda.
- Carrito guardado solo en el navegador.
- Preparación de una consulta para WhatsApp.
- Información de entregas locales en Quito y Ambato.

## Antes de publicar para ventas reales
1. Sustituir productos, precios, emojis y descripciones por el inventario real.
2. Incorporar el logotipo oficial de Shop ti ec.
3. Configurar y probar el número oficial de WhatsApp.
4. Definir costos, horarios, zonas y condiciones de entrega.
5. La demo no procesa pagos ni guarda pedidos en servidor.
6. No hay todavía generador de anuncios con IA ni publicación automática en redes sociales; esas integraciones se evaluarán por separado y no se activarán servicios de pago sin autorización.

## Probar
Abre el archivo index.html en un navegador. No requiere compilación.

## Publicación gratuita
Este repositorio se puede conectar a un servicio de alojamiento estático compatible, como Cloudflare Pages. Revisa los términos y límites vigentes del proveedor antes de usarlo comercialmente. No contiene claves privadas ni credenciales.
